============================================================
CORE PRODUCT IDEA
============================================================

The central idea of the entire product is:

EVERY ROBOT IS AN AUTONOMOUS AGENT.

The robots themselves must:

- observe
- understand their local environment
- predict future conflicts
- plan routes
- communicate with other robots
- negotiate access to shared warehouse resources
- allocate/reallocate tasks
- avoid collisions
- detect deadlocks
- resolve deadlocks
- detect blocked aisles
- reroute automatically
- manage battery
- handle communication failures
- handle robot failures
- recover from unexpected situations
- continue operating without a central fleet brain

The dashboard is ONLY an observation and analysis layer.

The dashboard must NOT be the decision maker.

The user must NOT manually control robot decisions.

The user may inject disturbances into the environment, but after the disturbance the robots must solve the problem automatically.

============================================================
THE MOST IMPORTANT TEST
============================================================

The application must pass this test:

If the dashboard/control UI disappears, the robot agents should still conceptually be capable of:

- maintaining local state
- planning
- communicating peer-to-peer
- negotiating
- avoiding collisions
- rerouting
- detecting deadlocks
- recovering
- completing tasks

The UI is a digital twin and observability layer.

The autonomous agents are the actual product.

============================================================
ROUTE PLANNING
============================================================

Implement A* or equivalent graph-based path planning.

Route cost must include:

distance
+ predicted travel time
+ congestion
+ reservation conflicts
+ blockage
+ battery cost
+ collision risk
+ expected waiting
+ task urgency

Therefore:

SHORTEST PATH != ALWAYS BEST PATH

The robot must be capable of deliberately choosing a slightly longer path because it is faster or safer.
